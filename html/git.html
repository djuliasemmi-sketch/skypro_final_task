Git

Инициализация и клонирование

  • git init — создать новый локальный репозиторий в текущей папке.
  • git clone — скопировать удалённый репозиторий со всей историей

Базовый рабочий процесс

  • git status — показать состояние файлов в рабочем каталоге и индексе.
  • git add <файл> (или git add .) — добавить изменения в индекс (staging area).
  • git commit -m "сообщение" — сохранить проиндексированные изменения в истории.
  • git diff — посмотреть разницу между файлами.
  • git log — показать историю коммитов.

Ветвление

  • git branch — посмотреть список локальных веток.
  • git branch — создать новую ветку.
  • git switch (или git checkout ) — переключиться на ветку.
  • git merge — влить указанную ветку в текущую.

Удалённые репозитории

  • git remote -v — посмотреть список подключенных удалённых репозиториев.
  • git fetch — скачать изменения с удалённого сервера без их слияния.
  • git pull — скачать изменения с сервера и сразу выполнить слияние.
  • git push — отправить локальные коммиты в удалённый репозиторий.

Стандартные команды

  • ls - расшифровывается как "List files in the directory", что переводится как "перечислить все файлы в папке" или "вывести на экран список файлов в папке".
  • cd - расшифровывается как "Change directory", что переводится как "сменить папку" или "перейти в другую папку".
  • pwd - расшифровывается как "Present working directory", что переводится как "текущая рабочая директория". То есть команда pwd показывает, в какой сейчас папке мы находимся.
  • mkdir - расшифровывается как "Make directory", что переводится как "создать папку".
  • mv - расшифровывается как"Move", что переводится как "переместить", "передвинуть".
